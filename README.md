Objetivo del proyecto identificar la utilización de los planes telefonicos, de acuerdo a los usos en llamadas y mensajes, así como las edades en las que se concentra la mayor cantidad de usuarios.
Fueron utilizados 3 datasets users, plans, usage para poder obtener los datos necesarios, lo primero fue conocer la información de cada datasets y a su vez conocer si tienen datos faltantes o si existe información que no va de acuerdo a lo que se refiere cada columna, por lo que limpiamos bien cada unos de los datasets, para poder trabajar con ellos y poder juntar las bases de datos y tener solo un dataset que fue user_profile, teniendo esa base de datos fuimos estableciendo las funciones para determinar el uso del plan y los grupos de edades en las que se dispersan los datos de los planes, para identificar su uso y que edades son las que mas utilizan los planes, para eso fue importante establecer el rango de datos necesarios para determinarlos.
Para abrirlo, es ingresar en el link y validar los datos.
